# Команды

См. также: [сценарии использования](01-use-cases.md), [архитектура процесса](03-architecture.md).

Пользователь работает в интерактивном режиме командной строки: инструмент
выводит приглашение к вводу, пользователь вводит одно из перечисленных ниже
слов и нажимает Enter, инструмент выполняет действие и сообщает результат.

Перед тем как принять первую команду, инструмент самостоятельно, без участия
пользователя:

1. читает файл конфигурации переноса из рабочей папки;
2. запрашивает у пользователя учётные данные и выполняет вход в PLM-систему;
3. открывает рабочую сессию изменений (см. [сценарий 2](01-use-cases.md#сценарий-2-запуск-переноса)).

Только после этого становятся доступны команды.

## Справка

Команда, показывающая приветственное сообщение и краткую информацию об
инструменте. Используется для проверки, что инструмент запущен и готов к
работе.

- **Ввод:** слово-команда.
- **Ответ:** текстовое приветствие.
- **Побочный эффект в системе:** нет.

## Запуск переноса

Основная команда — запускает перенос данных из подготовленного файла
спецификации в PLM-систему, всеми этапами последовательно (см.
[архитектуру процесса](03-architecture.md)).

- **Ввод:** слово-команда.
- **Ответ:** сообщения о ходе выполнения по мере прохождения этапов; по
  завершении — сводка результата (что и в каком количестве создано, что
  пропущено — см. [логирование](05-logging.md)).
- **Побочный эффект в системе:** в PLM-системе создаются объекты, связи и
  атрибуты — но пока не подтверждена сессия (см. команду завершения ниже), эти
  изменения не видны никому, кроме текущего запуска.
- Команду можно вводить повторно в рамках одной сессии — каждый повтор
  выполняет перенос заново поверх уже созданных в этой сессии данных (без
  проверки на дубли).

## Завершение работы

Команда, которая подтверждает результат переноса (делает его видимым для
остальных пользователей PLM-системы) и закрывает сессию инструмента.

- **Ввод:** слово-команда.
- **Ответ:** подтверждение завершения.
- **Побочный эффект в системе:** все изменения текущей сессии становятся
  видимы всем пользователям PLM-системы; сессия закрывается.
- **Важно:** это единственный способ сделать результат переноса видимым
  снаружи. Если завершить работу инструмента любым другим способом (закрыть
  окно, прервать процесс) без этой команды — результат переноса останется
  недоступен, а сессия — незакрытой в PLM-системе (см.
  [известные ограничения](06-known-limitations.md)).
