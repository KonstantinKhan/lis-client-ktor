# Назначение и основные понятия

См. также: [сценарии использования](01-use-cases.md), [архитектура процесса](03-architecture.md).

## Назначение

Инструмент переносит структуру изделия из файла-спецификации (Excel) в
PLM-систему (систему управления жизненным циклом изделия), в которой ведётся
конструкторско-технологическая структура изделий предприятия.

Источник данных — файл спецификации изделия, оформленный в привычном для
конструкторов и технологов виде: перечень позиций (деталей, сборочных единиц,
материалов, стандартных изделий и т.п.) и связи между ними (что из чего
состоит, в каком количестве).

Результат — та же структура изделия, но созданная как набор связанных объектов
внутри PLM-системы: с назначенными типами, атрибутами (наименование, масса,
марка материала, ГОСТ и т.п.), связями состава ("Состоит из ...") и, для
материалов, связями с внешним справочником материалов и классификаторов.

## Кому нужен инструмент

- Специалист по нормативно-справочной информации / конструкторско-технологической
  подготовке производства, отвечающий за перенос спецификаций изделий в
  PLM-систему.
- Инструмент запускается вручную, на одно изделие (один файл спецификации) —
  за один запуск переносится состав одного изделия целиком.

## Что не входит в задачу инструмента

- Инструмент не редактирует исходный файл спецификации и не проверяет его на
  соответствие ГОСТ — ожидается, что файл уже прошёл нормоконтроль на
  предыдущих этапах.
- Инструмент не откатывает частично выполненную миграцию автоматически —
  повторный запуск создаёт данные заново (см. [известные ограничения](06-known-limitations.md)).

## Ключевые понятия

| Термин | Значение |
|---|---|
| Спецификация изделия | Документ, описывающий состав изделия — перечень входящих деталей, сборочных единиц, материалов и т.п. (оформляется по ГОСТ 2.106) |
| Раздел спецификации | Стандартная классификация позиции в спецификации: "Сборочные единицы", "Детали", "Стандартные изделия", "Прочие изделия", "Материалы" и т.п. |
| ДСЕ | Деталь или сборочная единица — собирательный термин для позиции состава изделия, в отличие от материала или стандартного изделия |
| Код классификатора | Числовой код, однозначно идентифицирующий позицию спецификации; используется, чтобы связать между собой родительские и дочерние позиции состава |
| КД (конструкторская документация) | Основание, по которому изделию/детали назначается материал — "материал по КД" означает материал, заданный конструкторской документацией, а не технологией изготовления |
| Собственная спецификация (условно "DS" в данных) | Признак того, что у сборочной единицы есть отдельно оформленный состав (как у самостоятельного изделия), а не только позиция в составе родителя |
| Сортамент | Способ идентификации материала по стандартизованному коду (ГОСТ/классификатор), в отличие от произвольного текстового обозначения |
| Справочник материалов и классификаторов | Внешняя система нормативно-справочной информации, в которой ведутся материалы и коды классификаторов; используется инструментом для поиска и создания материалов |
| Заготовка | Объект, из которого изготавливается деталь (прокат, отливка, поковка и т.п.), с собственным основным материалом и нормой расхода |
| Группа замены | Формальное описание в PLM-системе того, что один материал (или объект) может быть заменён на другой — с явным указанием, какой вариант основной, а какой — заменитель |
| Группа аналогов | Аналогичный механизм для взаимозаменяемых вариантов состава изделия (не только материалов) |
