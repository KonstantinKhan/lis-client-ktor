# CLAUDE

## Основные правила работы (STRICT)

- перед выполнением задачи обязательно использовать информацию из `wiki`, точка входа `index.md`
- после изучения индекса по описанию находи релевантные знания и используй их в работе
- для работы с кодовой базой используй преимущественно инструменты `ast-index`
- если сомневаешься - спроси через `AskUserQuestion`
- завершающим этапом работы всегда является проверка того, что билд собирается, самому ничего запускать и проверять не
  нужно, нужно дождаться результатов проверки пользователем и следующей задаче
- все запускаемые субагенты должны следовать правилам работы с `wiki`
